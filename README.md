# C++ CHIP-8 Emulator

CHIP-8 Emulator written in C++.

3 public domain ROMs come included in the 'roms' directory

## Compiling & Running

Requires SDL3:
```
sudo apt install libsdl3-dev
```

Compiling:
```
make
```

Running:
```
./chip8 <ROM file path>
```
